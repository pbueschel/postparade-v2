PostParade v2 · design exploration · 2026-08-06

Direction B — modern pass

Variant B's palette, unchanged: parchment ground, forest-green chrome, gold and oxblood accents. What changes is the structure — rounded cards and controls, list views instead of ruled tables, info boxes, stat tiles, segmented controls, soft shadows. Serif display headings stay as the classic anchor; monospace is reserved for data that wants to line up.

What changed from the original B. Palette, type family, and every colour value are identical. The structure is not: rounded cards and controls replace hairline-ruled panels, the roster is a list view rather than a table, notices became info boxes, the three dashboard panels became stat tiles with meters, the tab strip became a segmented control, and the meets grid became separate cards on the parchment ground.

What stayed classic. Source Serif display headings, and monospace on data that wants to line up — times, money, records, and the condition text, which still reads better as a typed book than as UI copy.

The trade. Modern structure costs vertical space: seven horses here occupy roughly what nine did in the ruled table. If the roster is the screen trainers live in, that matters — a density toggle on the list view would settle it. Rule 0 holds: nothing here rates, ranks, or forecasts.
