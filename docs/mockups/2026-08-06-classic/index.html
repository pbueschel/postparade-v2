How to read these. One markup, three themes — every difference between the directions is a CSS custom property, so the screens are comparable like for like. Nothing here is wired to app/; no gates run against this file.

What each direction commits to. Paddock keeps the current palette and changes only the typography — cheapest to adopt, least distinctive. Condition Book is the partner's treatment: parchment ground, forest-green chrome, gold and oxblood accents. Racing Form pushes to newsprint — no round corners, ruled tables, tighter rows, gold on near-black chrome. Most characterful, most work to hold consistent across every screen.

Rule 0 holds. Nothing on these screens rates, ranks, or forecasts. Records, earnings, spots, and timestamps are facts; the preference clause is flagged and never ruled on.
